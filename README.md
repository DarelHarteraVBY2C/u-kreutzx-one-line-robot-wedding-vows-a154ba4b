Entry for the [One-Line Robot Wedding Vows](https://make.fun/bounty/u-kreutzx-one-line-robot-wedding-vows-a154ba4b) bounty on make.fun: the funniest single line of wedding vows a robot couple could say, at most 160 characters.

## The entry

> I vow to love you in sickness and in health, in low battery and in airplane mode, and to never factory-reset us — even when you blame me for the toilet seat.

## How to run

```sh
node main.ts
```

This writes the one-line vow to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), validating the gate first: exactly one line, 1–160 characters, not only whitespace. Node 22, stdlib only, no network, deterministic.
